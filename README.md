# Разработка сценариев и рабочих листов

Репозиторий для совместной разработки сценариев и рабочих листов в VS Code с использованием Claude.

## Что хранить в репозитории

- сценарии и их версии;
- рабочие листы и шаблоны;
- исходные материалы, необходимые для проекта;
- инструкции по сборке, проверке и использованию результатов.

Не добавляйте пароли, API-ключи, токены, персональные данные и локальные файлы с настройками доступа.

## Рекомендуемая структура

```text
scenarios/       # сценарии
worksheets/      # рабочие листы
templates/       # шаблоны
docs/            # документация и требования
assets/          # изображения и другие материалы
```

Структуру можно изменить под фактический проект.

## Первая загрузка существующих наработок

Самый безопасный вариант — клонировать репозиторий в новую папку, а затем скопировать в неё файлы проекта:

```bash
git clone https://github.com/Dmirty-M/scenario-worksheet-development.git
cd scenario-worksheet-development
```

Скопируйте существующие наработки в эту папку, затем выполните:

```bash
git add .
git status
git commit -m "Добавить текущие наработки"
git push origin main
```

Перед командой `git commit` проверьте вывод `git status` и убедитесь, что в список не попали секреты, временные файлы или персональные данные.

## Дальнейшая работа

Перед началом работы получайте актуальные изменения:

```bash
git pull --rebase origin main
```

После завершения логического блока работы:

```bash
git add .
git status
git commit -m "Краткое описание изменений"
git push origin main
```
